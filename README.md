# ספריית ההשקעות המוקלטת

Static site (GitHub Pages): Hebrew RTL catalog of investment-book audio summaries.
- `index.html` - the whole site (RTL, search, category filter, cards, embedded audio players)
- `books.js` - the catalog data (549 items, 19 categories + sources chapter)
- `audio/` - MP3 recordings, added gradually

Covers load client-side from Open Library.
